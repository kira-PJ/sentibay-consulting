Step 3: Launch a Windows Instance

This is where the fun begins. You're about to create a virtual computer running Windows — in the cloud!

3.1 Start the Launch Wizard

Click the orange "Launch instance" button.

3.2 Name Your Instance

Under "Name and tags", type: AfChix-YourName (e.g., AfChix-Grace)

Give your instance a name with YOUR name in it

3.3 Choose Windows

  1. Under "Application and OS Images", click the "Windows" tab
  2. Select "Microsoft Windows Server 2025 Base" (Free tier eligible)

Click the Windows tab and select Windows Server 2025

💡 What is an AMI? AMI = Amazon Machine Image. It's a template that tells AWS which operating system to install. We picked Windows because most people are familiar with it.

3.4 Choose Instance Size

Under "Instance type", change from t3.micro to t3.medium (2 vCPU, 4 GiB memory).

💡 What is an instance type? This is the "size" of your virtual computer. Think of it like choosing between a studio apartment (t3.micro, 1GB RAM) and a one-bedroom (t3.medium, 4GB RAM). Windows needs more space to run smoothly.

3.5 Create a Key Pair

⚠️ Do NOT select from the dropdown! You may see other people's key pairs there. Always click "Create new key pair".
  1. Click "Create new key pair"
  2. Key pair name: key-yourname (e.g., key-grace)
  3. Key pair type: RSA
  4. Format: .pem
  5. Click "Create key pair"
  6. A .pem file will download — keep this file safe!

Fill in your name and click Create key pair

The .pem file downloads to your computer

💡 What is a key pair? It's like a special lock and key for your machine. The .pem file is the "key" that proves you're the owner. Without it, you can't get the password to log in.

3.6 Network Settings (Firewall)

Click "Edit" on the Network settings section, then check these boxes:

  • ✅ Allow RDP traffic from — Anywhere (0.0.0.0/0)
  • ✅ Allow HTTP traffic from the internet

Make sure RDP and HTTP are both checked

💡 What are these? Think of them as doors on your apartment:
• RDP (port 3389) = the door YOU use to walk in and control your machine
• HTTP (port 80) = the shop window that lets visitors see your website

3.7 Launch!

  1. Leave everything else as default
  2. Click the orange "Launch instance" button at the bottom
  3. You'll see: ✅ "Successfully initiated launch of instance"
  4. Click "View all instances"

Success! Your virtual machine is being created

Now we'll connect to your Windows machine using Remote Desktop — you'll see and control the full Windows desktop from your laptop.

4.1 Get Your Windows Password

  2. Click "Actions" > "Security" > "Get Windows password"
  3. Click "Upload private key file"
  4. Select the .pem file you downloaded earlier
  5. Click "Decrypt password"
  6. COPY THE PASSWORD — you'll need it next

Upload your .pem file to decrypt the password

Copy this password! You'll need it to log in

⏱️ Note: The password may take up to 4 minutes to become available after launch. If you see "Password is not available yet", wait and try again.

4.2 Connect Using Remote Desktop

  1. Select your instance > Click "Connect"
  2. Click the "RDP client" tab
  3. Click "Download remote desktop file"
  4. Open the downloaded .rdp file

Download the remote desktop file

You'll see several popups — here's what to do with each:

  1. "Opening Remote Desktop Connection" → Click OK
  2. "Remote Desktop Connection security warning" → Check Clipboard, click "Connect"
  3. "Enter your credentials" → Click "More choices" > "Use a different account" → Username: Administrator → Password: paste the password you copied → Click OK
  4. "Identity cannot be verified" → Click "Yes"

This is normal — click Connect

Enter Administrator and paste your password

Step 4 (Mac): Connect from a Mac

If you're using a Mac, follow these steps instead of the Windows RDP instructions above.

4M.1 Install Microsoft Remote Desktop

  1. Open the App Store on your Mac (the blue "A" icon in your dock)
  2. Search for "Microsoft Remote Desktop"
  3. Click Get then Install (it's free)
  4. Wait for it to download and install
⚠️ Do this BEFORE the workshop! App Store downloads can be slow on shared wifi.

4M.2 Get Your Password (Same as Windows)

  1. In the AWS Console, select your instance
  2. Click "Actions" > "Security" > "Get Windows password"
  3. Click "Upload private key file" and select your .pem file from Downloads
  4. Click "Decrypt password"
  5. Copy the password (Cmd+C)

4M.3 Connect Using the .rdp File

  1. In the AWS Console, click "Connect" > "RDP client" tab
  2. Click "Download remote desktop file"
  3. The .rdp file downloads to your Downloads folder
  4. Double-click the .rdp file — it opens in Microsoft Remote Desktop

4M.4 Enter Credentials

  1. A login window appears asking for credentials
  2. Username: Administrator
  3. Password: paste the password you copied (Cmd+V)
  4. Click "Continue"

4M.5 Accept the Certificate

  1. You'll see a warning: "The certificate could not be verified..."
  2. Click "Continue" — this is safe, you just created this machine
🎉 You should now see the Windows desktop in a window on your Mac! You can resize it, go full screen (green button), or use Cmd+F to toggle.

Helpful Mac Tips

  • Copy/Paste between Mac and Windows: Cmd+C on Mac, then Ctrl+V inside the Windows session
  • Full screen: Click the green circle (top-left of window) or use Cmd+F
  • Exit full screen: Move mouse to top of screen, click the green circle again
  • Right-click: Two-finger tap on trackpad, or Ctrl+click

Step 4 (Linux): Connect from Linux

If you're using Ubuntu, Fedora, or another Linux distro, follow these steps.

4L.1 Install Remmina (if not already installed)

Remmina is pre-installed on most Ubuntu systems. If not:

sudo apt install remmina remmina-plugin-rdp

On Fedora:

sudo dnf install remmina remmina-plugins-rdp

4L.2 Get Your Password (Same as Windows/Mac)

  1. In the AWS Console, select your instance
  2. Click "Actions" > "Security" > "Get Windows password"
  3. Upload your .pem file and click "Decrypt password"
  4. Copy the password

4L.3 Connect with Remmina

  1. Open Remmina from your applications menu
  2. In the top bar, select RDP from the protocol dropdown
  3. In the address field, paste your instance's Public IPv4 address
  4. Press Enter to connect

4L.4 Enter Credentials

  1. Username: Administrator
  2. Password: paste the decrypted password
  3. Domain: leave blank
  4. Click OK or Connect

4L.5 Accept the Certificate

  1. You'll see a certificate warning
  2. Click "Yes" or "Accept"
🎉 You should now see the Windows desktop inside Remmina!

Alternative: Using xfreerdp (command line)

If Remmina doesn't work, you can connect via terminal:

xfreerdp /v:YOUR-PUBLIC-IP /u:Administrator /p:'YOUR-PASSWORD' /size:1280x720

Replace YOUR-PUBLIC-IP and YOUR-PASSWORD with your actual values.

Helpful Linux Tips

  • Copy/Paste: Ctrl+C on Linux, then Ctrl+V inside the Windows session
  • Full screen: Press Ctrl+Shift+F in Remmina
  • Exit full screen: Press Ctrl+Shift+F again
  • If connection fails: Make sure the instance's security group allows port 3389 from your IP
✅ Connected? Whether you used Windows, Mac, or Linux — you should now be looking at a Windows Server desktop. Continue to Step 5 below. The remaining steps are the same for everyone.

Step 5: Deploy the AfChix Market Website

Now for the coolest part — you'll install a web server and deploy a real shopping website. Anyone in the world will be able to see it!

5.1 Open PowerShell

On your Windows remote desktop, click the Start menu and find "Windows PowerShell" (blue icon).

Find Windows PowerShell in the Start menu

💡 What is PowerShell? A command-line tool that lets you control the computer by typing instructions instead of clicking buttons. System administrators use this daily.

5.2 Install IIS (Web Server)

Type this command and press Enter:

Install-WindowsFeature -name Web-Server -IncludeManagementTools

What this does: Installs IIS (Internet Information Services) — Microsoft's web server software. Without it, your machine wouldn't know how to serve web pages to visitors.

Wait 1-2 minutes. You'll see "Success: True" when done.

5.3 Download the Website

Type this command:

Invoke-WebRequest -Uri "https://github.com/kira-PJ/afchix-cloud-workshop/archive/refs/heads/main.zip" -OutFile "C:\website.zip"

What this does: Goes to GitHub (where our website code is stored), downloads it as a zip file, and saves it to the server. Like downloading a file from the internet — but via command line.

5.4 Extract the Files

Expand-Archive -Path "C:\website.zip" -DestinationPath "C:\website" -Force

What this does: Unzips the downloaded file. Like right-clicking a .zip and choosing "Extract All".

5.5 Copy to Web Server Folder

Copy-Item -Path "C:\website\afchix-cloud-workshop-main\*" -Destination "C:\inetpub\wwwroot\" -Recurse -Force

What this does: Copies all website files into IIS's special folder (C:\inetpub\wwwroot\). Anything placed here automatically becomes a live website. Like putting products on the shelf in your shop — once they're there, customers can see them.

All 4 commands completed successfully

5.6 View Your Live Website!

  1. Go back to your laptop (not the remote desktop)
  2. Open a new browser tab
  3. Find your instance's Public IPv4 address in the EC2 Console
  4. Type in your browser: http://YOUR-PUBLIC-IP (e.g., http://98.93.29.34)
🎉 You should see the AfChix Market website! A beautiful purple and pink shopping site with Kiondo bags, Maasai bracelets, coffee, and more!

YOUR website, hosted on YOUR virtual machine, live on the internet!

💡 Notice the IP address in the browser bar — this is your machine's address on the internet. If you shared this IP with a friend in another country, they could see this website too. This is exactly how real websites work!

5.7 Personalize Your Website (Make it Yours!)

Let's add your name to the website. In PowerShell, type this command (replace YourName with your actual name):

(Get-Content "C:\inetpub\wwwroot\index.html") -replace "Built by AfChix Workshop Participants", "Built by YourName at AfChix Workshop" | Set-Content "C:\inetpub\wwwroot\index.html"

Example: If your name is Grace:

(Get-Content "C:\inetpub\wwwroot\index.html") -replace "Built by AfChix Workshop Participants", "Built by Grace at AfChix Workshop" | Set-Content "C:\inetpub\wwwroot\index.html"

What this does: Opens the website file, finds specific text, replaces it with your name, and saves. This is real web development — editing a live website!

Now refresh your browser — you'll see your name on the pink badge! 📸 Take a screenshot!

Step 6: Clean Up

When you're done with a cloud resource, always delete it. Otherwise it keeps running and costs money.

  1. Go to EC2 Dashboard > Instances
  2. Select your instance (checkbox next to your name)
  3. Click "Instance state" > "Terminate (delete) instance"
  4. Click "Terminate (delete)" to confirm

Select Terminate (delete) instance

Confirm termination — your machine will be deleted

💰 Why this matters: A t3.medium costs ~$0.04/hour = ~$30/month if you forget. In the real world, forgetting to terminate is how people get surprise AWS bills!
